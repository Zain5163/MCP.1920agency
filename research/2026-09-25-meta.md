# Facebook Pages and Instagram — limits verified against live docs

**Date:** 2026-09-25
**Why:** tier 0.3 — every platform limit in the code was from knowledge, not from
documentation. Checking found three errors.

## Three things that were wrong

| What we had | What is true |
|---|---|
| Instagram rate limit **50** posts / 24h | **100** per 24h. The 50 figure is stale. A carousel counts as one |
| Aspect ratio **not checked at all** | Must be **0.8 (4:5 portrait) to 1.91:1 landscape**. Outside it, container creation fails with an error that reads like a permissions problem |
| Graph API pinned at **v21.0** | **v25.0**. v20 was deprecated 2026-09-24 |

## VERIFIED — Instagram

- **Cannot post text alone** — hence `minMediaCount: 1`.
- Two-step **create-then-publish container** flow. The media URL must stay
  reachable across *both* steps.
- Reels up to 15 minutes.
- Media is **fetched by Instagram over HTTPS**, not uploaded — so object storage
  is mandatory for Instagram and not for Facebook.

### The documented restriction that is not enforced

Docs say **JPEG only** — PNG, WebP and GIF are listed as unsupported. In practice
a **PNG published successfully on 2026-09-25**.

Decision: do **not** block PNG. Rejecting something that demonstrably works would
be worse than the documented risk. Revisit if a PNG ever fails. Recorded here
because this is a deliberate departure from documentation, not an oversight.

## VERIFIED — Facebook Pages

- Accepts JPG, PNG, GIF, MP4.
- Uploads bytes directly, so it works with no object storage at all.
- Text limit: the widely-cited **63,206**. Meta does not publish an exact figure
  and secondary sources also quote 50,000 — treat as approximate. It is far beyond
  any realistic caption either way.
- Native scheduling exists (`published=false` plus `scheduled_publish_time`,
  ~10 minutes minimum lead time). **Our own queue is used instead, so that path is
  untested.**

## Token behaviour

A Page token lives as long as the app stays installed and has nothing to refresh —
unlike Threads and Pinterest. But **page tokens inherit the lifetime of the user
token they were derived from**, so pages must be fetched with the *long-lived*
user token. Fetching them with the short-lived one yields page tokens that die
within the hour.

## Status

**Verified live.** Six real posts published — four to the 1920 Agency Facebook
Page, two to Instagram. This is the only platform pair proven end to end.
