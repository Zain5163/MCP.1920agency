# Media

Drop images and videos here to post them. No need to tell me a full path — just
say which file, or "the newest one".

```
media/to-post/     put new files here
media/posted/      moved here after publishing, so it is obvious what has gone out
```

## What works where

| | Facebook | Instagram |
|---|---|---|
| Images | JPG, PNG, GIF, WEBP | JPG, PNG |
| Video | MP4, MOV | MP4 (published as a Reel) |
| Text-only post | Yes | **No — Instagram always needs media** |
| Ideal size | any sensible size | **1080x1080 or larger** |

Instagram accepts images under 1080px but re-compresses them and the result looks
noticeably softer, so export at 1080x1080 or bigger where it matters.

## Why files are not committed

`.gitignore` excludes everything in here except this README. Media would bloat the
repository, and some of it is client work that does not belong in version control.
The files stay on this machine; only the code is tracked.
